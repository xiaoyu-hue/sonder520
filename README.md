# Sonder · 个人工作生活 App

只在本机浏览器本地运行的个人工作/生活管理工具，不需要联网、登录、部署、手机端。

## 如何运行

直接用浏览器打开（双击） `index.html` 即可。推荐 Chrome / Edge。

- 数据保存在浏览器本地存储（localStorage），**刷新、关闭标签、关闭并重启浏览器都不丢失**。
- 重要数据请定期在「数据与设置 → 导出备份」下载 JSON 文件保存。

## 功能
- 首页总览：今日摘要、快速备忘、六个工作模块概览卡片
- 今日计划：任务 增/删/改/勾选/排序，过期与已完成分组
- 快速备忘：即点即存、历史、归档
- 自媒体：选题/内容、标签与状态筛选、导出 CSV
- 开发工作：项目、任务清单、进度自动统计、技术笔记
- 咨询工作：客户档案、项目、跟进记录、收入记录
- 阅读计划：书单、状态、进度、读书笔记
- 看新闻计划：资讯收藏、待读/已读/收藏、跳转链接
- 设计计划：灵感收集 + 设计项目与阶段
- 数据与设置：主题、模块开关、统计、导出/导入备份

## 开发者
依赖与说明：

- 应用为纯 HTML/CSS/原生 JS，构建/运行零依赖，不需要 npm 安装即可使用。
- 开发测试：`npm install`（安装 jsdom）后运行 `npm test`。
- 运行全部测试：`npm test`
