## 🎯 项目简介

**Sonder520** 是一款**零后端、纯前端**的个人工作与生活管理工具，由 AI Agent 辅助开发。项目以「水墨 × 液态玻璃」为视觉语言，将效率工具与东方美学融合。

| 🎨 **水墨风格** | 宣纸/墨黑双主题，液态玻璃卡片设计 |

| 🎮 **内置游戏** | 井字棋、五子棋、扫雷等 6 款迷你游戏 |
| 🧪 **测试完备** | 696 项测试全绿，质量有保障 |

## 🛠️ 技术架构

### Sonder-Frame 渐进式框架

```
Application (应用层)
    ↓
ModuleFactory (标准模块工厂)
    ↓
VisualEngine + EventBridge (UI渲染 + 事件总线)
    ↓
TrustLayer (安全存储层)
    ↓
IDB (主存储) + localStorage (副本) + Crypto (加密)
```

### 核心技术栈

| 技术 | 用途 |
|------|------|
| **HTML5** | 语义化结构 |
| **CSS3** | 液态玻璃设计、水墨风格、响应式布局 |
| **原生 JavaScript** | 零依赖、零构建、高性能 |
| **IndexedDB** | 主数据存储（真源） |
| **localStorage** | 副本存储 + 跨标签信号 |
| **Crypto API** | PBKDF2 + AES-GCM-256 加密 |
| **Web Worker** | 五子棋 AI 异步计算 |
| **PWA** | 离线可用、安装到桌面 |
| **Playwright** | E2E 测试（三端：桌面/平板/手机） |

### 质量保障

- ✅ **696 项测试**全绿（单元测试 + 契约测试 + 集成测试 + E2E）
- ✅ **零构建**类型检查（JSDoc + TypeScript）
- ✅ **ESLint** 代码规范
- ✅ **14 份 ADR** 架构决策记录

## 🚀 快速开始

### 在线使用（推荐）

访问 https://sonder520.pages.dev/ 立即使用，无需安装。

### 本地运行

1. 克隆仓库：
```bash
git clone https://github.com/xiaoyu-hue/sonder520.git
cd sonder520
```

2. 直接在浏览器打开 `index.html`（双击即可）

> 💡 推荐 Chrome / Edge 浏览器

### 数据管理

- 数据存储在浏览器本地（localStorage + IndexedDB）
- 定期通过「数据与设置 → 导出备份」下载 JSON 备份
- 可在设置中开启加密存储（PBKDF2 + AES-GCM）

## 📦 本地运行与开发

### 环境要求

- Node.js 18+
- npm 9+

### 开发命令

```bash
# 安装依赖
npm install

# 运行所有测试
npm test

# 类型检查（零构建）
npm run typecheck

# 代码规范检查
npm run lint

# E2E 测试（Playwright）
npm run test:e2e

# 同步 Service Worker 缓存
npm run sync-sw
```

### 测试覆盖

- **单元测试**：存储、加密、TrustLayer

- **集成测试**：Factory+TrustLayer、Factory+VisualEngine、Module+EventBridge
- **E2E 测试**：Playwright 三端（桌面/平板/手机）
