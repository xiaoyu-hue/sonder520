# Sonder · 个人工作生活 App

个人工作/生活管理工具，纯 HTML/CSS/原生 JS，零构建、零依赖。可在电脑本地运行，也可部署到任意静态托管后在手机/电脑上访问。

## 如何运行（本地）

直接用浏览器打开（双击） `index.html` 即可。推荐 Chrome / Edge。

- 数据保存在浏览器本地存储（localStorage），**刷新、关闭标签、关闭并重启浏览器都不丢失**。
- 重要数据请定期在「数据与设置 → 导出备份」下载 JSON 文件保存。

## 在手机上打开（线上部署）

项目全部资源为相对路径，可直接上传到任意静态托管平台：

1. **Netlify Drop（最省事，推荐）**：打开 https://app.netlify.com/drop ，把本目录（含 `index.html` / `css` / `js` / `img`）整个拖进去，稍等即获得一个 `https://xxx.netlify.app` 网址，手机或电脑浏览器打开即用。
2. **GitHub Pages**：新建仓库，把本目录推上去；在 Settings → Pages 里选 `main` 分支 / root 目录发布。
3. **Cloudflare Pages / Vercel**：导入目录直接部署，无需构建命令。

> 注意：手机浏览器里的数据存于**该手机浏览器的 localStorage**，与电脑上互不相通（不同设备数据独立）。
> 如需多设备数据同步，可另行在「数据与设置」里导出/导入备份。

## 手机适配

- 窄屏（≤720px）下侧栏自动变为**底部液态玻璃导航栏**（图标式，可横向滚动）。
- 已做 `viewport-fit=cover`、刘海屏/手势条安全区（`env(safe-area-inset-bottom)`）、触控目标 ≥44px、防止 iOS 输入聚焦自动缩放。
- 支持「添加到主屏幕」/「添加到桌面」作为 App 图标打开（不依赖网络，只要静态托管在线即可）。

## 功能
- 首页总览：今日摘要、快速备忘、六个工作模块概览卡片
- 今日计划：任务 增/删/改/勾选/排序，过期与已完成分组
- 快速备忘：即点即存、历史、归档
- 自媒体：选题/内容、标签与状态筛选、导出 CSV
- 开发工作：项目、任务清单、进度自动统计、技术笔记
- 咨询工作：客户档案、项目、跟进记录、收入记录
- 阅读计划：书单、状态、进度、读书笔记
- 看新闻计划：资讯收藏、待读/已读/收藏、跳转链接
- 设计计划：灵感收集 + 设计项目与阶段
- 数据与设置：主题、壁纸透明度、模块开关、统计、导出/导入备份

## 开发者
依赖与说明：

- 应用为纯 HTML/CSS/原生 JS，构建/运行零依赖，不需要 npm 安装即可使用。
