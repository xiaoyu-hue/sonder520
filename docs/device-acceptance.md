# 真机验收清单

日期：2026-08-17
状态：进行中（每次发布前按本清单抽检）

适用范围：发布前在真实设备上抽检关键路径。本清单只列「模拟器覆盖不了、必须真机确认」的项；
其余功能由 tests/ 全量回归（npm test，当前 583 项）兜底。

## 设备矩阵

至少覆盖以下组合之一（每次发布任选一行抽检，重大改动全矩阵）：

| 组合 | 设备建议 | 必检区块 |
| --- | --- | --- |
| iOS Safari + 桌面 Chrome | iPhone（含刘海屏/灵动岛）+ Windows/Mac | 布局、PWA、游戏、存储 |
| Android Chrome + 桌面 Edge | Android 任意 + 其他桌面浏览器 | 布局、震动、PWA、通知 |
| Android + iOS 各一台 | 竖屏为主 | 触屏游戏、输入缩放、安全区 |

## A. 安装与离线（PWA）

- [ ] 「添加到主屏幕」后以独立窗口打开，无浏览器地址栏（standalone）
- [ ] 图标与名称正确显示（manifest.json）
- [ ] 断网（飞行模式）后重新打开：导航可用（网络优先回退缓存），页面不白屏
- [ ] 联网后刷新能拿到新版本（sw.js CACHE 版本号递增生效，见控制台或刷新后变化）
- [ ] 更新服务线程后旧缓存被清理（无重复叠加的旧资源）

## B. 布局与安全区（每个设备组合必检）

- [ ] 手机竖屏：底部导航栏贴合手势条，无刘海/圆角遮挡（env(safe-area-inset-bottom) 生效）
- [ ] 手机横屏：顶栏与导航变矮、不重叠、可滚动到底部内容不被遮挡
- [ ] 超小屏（≤360px，如 iPhone SE / 老安卓）：导航不挤爆、按钮不换行溢出
- [ ] 平板（721–960px）：侧栏折叠为 70px 图标栏且可点击
- [ ] 电脑（>960px）：左侧栏 + 多列网格正常；>1240px 内容限宽居中
- [ ] 全局无横向溢出滚动（横向滚动仅允许扫雷棋盘等容器内）

## C. 触屏交互（重点：游戏与长按）

- [ ] 扫雷：单击翻开、长按（~350ms）插旗、长按不误翻开、滚动中不误插旗
- [ ] 扫雷「再来一局 / 清空记录」等按钮触控面积 ≥44px 可点中
- [ ] 井字棋 / 五子棋：落子点准，AI 思考时界面不卡（Web Worker）
- [ ] 猜数字 / 猜成语 / 脑筋急转弯：输入框聚焦不触发页面缩放（字号 ≥16px）
- [ ] 游戏页返回上一页后对局状态正确（不残留 animating/DOM 状态）

## D. 表单与输入

- [ ] 所有文本输入在 iOS/Android 聚焦时不缩放页面
- [ ] 日期选择器在各系统原生控件可用（读书/媒体/任务日期字段）
- [ ] 弹窗在手机端为底部抽屉、桌面端为居中；键盘弹起时弹窗不被遮挡

## E. 存储、加密与备份

- [ ] 录入数据 → 刷新/杀进程 → 数据仍在（localStorage + IndexedDB 双写）
- [ ] 开启加密后：数据不可明文读取（DevTools 无明文）、重启后可解密
- [ ] 导出备份（JSON 下载）→ 导入恢复：完整往返，含游戏战绩与迷你游戏纪录
- [ ] 存储超 4.5MB 时顶部警示条出现（如有条件构造大数据量）

## F. 通知与动效

- [ ] 番茄专注结束：浏览器通知弹出（iOS 需先确认授权流程提示；Android 无碍）
- [ ] 页面动画在低端安卓不卡顿；「减弱动效」开启后动画大幅减少
- [ ] 壁纸上传 ≤2MB、透明度调节实时预览、恢复默认正常

## G. 每设备差异核对

- [ ] iOS 专用：长按文本不弹系统气泡（游戏棋盘）、home 指示条不透明遮挡、100dvh 高度正确
- [ ] Android 专用：拨动/vibrate 震动反馈生效（游戏插旗等）、通知授权引导正常
- [ ] 桌面右键扫雷插旗仍正常（回归：真机触屏长按不应影响桌面）
