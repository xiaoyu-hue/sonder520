# ADR 状态约定

每份 ADR 的标题下第一行必须写明状态，三态体系：

- **提议**：已提出，未最终拍板。可自由讨论/推翻。
- **已采纳**：已生效并持续指导代码。如需调整，先改 ADR 再改代码（或同 PR）。
- **已废弃**：被新 ADR 或演进条款替代，不再指导代码；保留以说明历史决策。
