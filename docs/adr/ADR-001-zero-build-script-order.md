# ADR-001：零构建 + index.html 脚本顺序为唯一依赖契约

- 状态：已采纳（2025 起持续生效）
- 背景：个人工作生活单机应用，需支持 `file://` 直接打开、任意静态托管一键部署、天然开源（访客 DevTools 可见全部源码）。
- 决策：
  1. 纯 HTML/CSS/原生 JS，零构建、零运行时依赖、无打包器。
  2. 模块间依赖关系**唯一真源 = index.html 中 `<script src="js/...">` 的出现顺序**（加载即依赖序）。
  3. 全部外部脚本 `defer`（不阻塞首屏解析，defer 保序执行，语义与同步加载一致）。
- 理由：零构建换来零供应链攻击面、零部署步骤、`file://` 可运行；顺序契约由 3 处测试守护（harness 注入序、shell 顺序断言、sync-sw 资源同步），依赖漂移在 CI 即暴露。
- 代价：
  - 全局命名空间隐式耦合：改模块内部签名无静态调用图保护，靠测试补位。
  - 无压缩/无 tree-shaking/无 sourcemap，首屏传输无压缩代码。
  - 规模成本：模块数增长后"人肉顺序"会失控。
- 演进：若模块规模超过承受阈值，优先引入浏览器原生 ESM（`type="module"`，仍是零构建），以 import 声明替代全局顺序契约。
